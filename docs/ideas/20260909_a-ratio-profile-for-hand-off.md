# Emit a ratio profile — `$X` and multiples — that the planners downstream can take

Retire, Eh? and the retirement toolkit both start where OWL Planner stops: with an annual
spending figure and a household's positions. Today the hand-off is a prompt a person writes by
hand from `budget.md`, translating to ratios as the planning article describes.

Write `owl-profile.yml` on every run: `X` (annual spending), then everything else as a multiple
of X — fixed obligations, savings rate, income, outstanding loans, known yearly items — with
no absolute figure other than X. It is the file to paste into an AI, and the shape a
downstream planner could import. It buys a durable, shareable output with the identifiers
already stripped; it costs a small writer and a decision about what belongs in it.
